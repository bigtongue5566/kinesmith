# 軟體、素材與輸出授權

核心工具免費不代表所有輸入素材均可商用。逐作品保存：名稱、來源 URL、版本、作者、license identifier、license text／條款快照、修改、用途、檔案 checksum、商用狀態與限制。未確認用 `unknown`，不可自動改成 cleared。

Canvas 是 Web 標準；Rough.js／p5.js／Three.js 常見版本分別是 MIT／LGPL-2.1／MIT（以鎖定版本附帶 LICENSE 為準）。Manim Community 為 MIT；Blender 為 GPL。GPL 的應用程式不自動把一般渲染作品變成 GPL，但散佈修改程式、二進位檔或 addons 時有各自義務。Kinesmith 本身 MIT 不覆蓋第三方授權。

FFmpeg build 可能是 LGPL 或 GPL，也可能包含 nonfree 元件。記錄 `ffmpeg -version`／`-buildconf` 及實際 encoder，發行包不擅自再散佈未知來源的 ffmpeg binary。VP9／Opus WebM 是本地預設；H.264/AAC MP4 需依 build、編碼器、專利與所在地實際義務判斷。程式能輸出不代表所有使用情境都已完成法律查核。

字型檢查 SIL OFL／Apache 等條款，附必要 notices；字型、字型產生的文字畫面與字型檔再散佈要分開判斷。不要把系統付費字型複製進通用 Plugin。

人聲引擎、聲庫、角色形象與聲音使用權各自記錄；即使聲庫免費下載，也可能禁止商用、要求標示角色、限制內容或再散佈。Opusmith 音符原創只證明 score 的來源，不能替代聲庫與取樣授權。

最終 Motion Report 列實際使用項目，未使用工具無須假稱成片包含。第三方 notices 保存在 `licenses/` 或版本化素材資料夾中。
