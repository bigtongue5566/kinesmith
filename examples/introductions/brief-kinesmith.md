# Kinesmith｜把想法鍛造成動態

原始需求：「範例不夠，幫我加一個介紹 Kinesmith 這個專案。」2026-10-25 建立版本 1。

48 秒，1920×1080，30fps，1440 個整數影格；繁體中文動態字排，無旁白。觀眾要記住：Kinesmith 為目前的 Codex／Claude Code 提供動態視覺創作方法，從想法一路產生可編輯、可重現的作品。

視覺像設計工作室的印刷海報：暖白、深綠黑、朱紅、萊姆綠；以可組裝的花形、字形、紙張及時間軸作主體。動作從聚合、分解、空間展開到定格；不使用股票影像、角色圖、外部生成模型或 OpenAI 商標圖案。

| 時間 | 敘事與動作 | 原生技術 |
|---|---|---|
| 0–6s | 花形聚合，Kine／smith 錯峰揭露 | Canvas |
| 6–12s | 一句創作需求展開成三張分鏡 | Canvas、遮罩 |
| 12–18s | 幾何、字排、手繪筆觸同場對話 | Canvas、真正 Rough.js |
| 18–24s | 五個金屬環由分散組成空間雕塑 | 真正 Three.js、光線、材質、相機 |
| 24–30s | 場景／圖層／波形與播放頭組成時間軸 | Canvas |
| 30–36s | 音樂波形與動態圖形雙向呼應 | Canvas、120BPM 精確時間 |
| 36–42s | 只替換中間場景，其餘保留 | Canvas、局部遮罩 |
| 42–48s | 花形與片名收束；46s 最後和弦，留 2 秒尾音 | Canvas |

配樂為 120BPM 切分電子樂，FM bell、柔和長音、低音與原創噪聲打擊。每 6 秒的章節與實際音符起音共用時間；最後主動作與 46 秒的終止和弦對齊。`compose.py` 保存完整音符／合成來源，MIDI 只是可編輯音符，不保證其他播放器還原相同音色。

作品介紹六種工具的能力；這支片本身實際使用 Canvas、Rough.js、Three.js，並未宣稱本片用到 p5、Manim 或 Blender。這三者的真實動畫仍在原有六引擎範例。Opusmith 協作為圖形說明，這次配樂由本專案原創合成器獨立完成。

共享字型為未修改的 Noto Sans TC（OFL-1.1），隨附完整授權。圖形與程式 MIT，原創配樂 CC0-1.0；第三方工具／編碼器依根目錄授權清單。客觀 QA、影格視覺檢查與主觀試聽分開記錄於成品報告。

修訂 2：在完整 1080p 成片的 34.9 秒影格發現協作鏡頭字幕與圓環相交。使用 `kinesmith revise` 只分叉 `kinesmith-06`，字幕下移、協作按鈕增加留白；原始時間軸及來源留在 `history/`。最終 project 使用此修訂，其他七幕與配樂不變；逐幕雜湊比對結果記錄於 Motion Report。
