# Opusmith｜把想法，寫成音樂。

原始需求：「再一個介紹opusmith這個專案」。2026-10-25 建立。逐字原文另存 `ORIGINAL_PROMPT-opusmith.txt`；音樂工作區的初始製作需求使用加空格的同義排版，既有版本與歷史不回寫。

沿用介紹作品系列的 48 秒、1920×1080、30fps、繁體中文、八幕、無旁白形式。
觀眾要記住：Opusmith 讓目前 Codex／Claude Code Agent 完成可編輯、可重建的音樂製作；不是另一個整曲生成 API。

視覺以黑膠唱片的旋轉、實際樂譜的音符、合成波形及分軌聚合為主體。炭黑、暖紙白、琥珀金與朱紅形成音樂工作室的色調；避免沿用 Codex 的檔案視窗構圖。上游沒有提供品牌圖示，因此直接排印 Opusmith 名稱，不杜撰官方 logo。
